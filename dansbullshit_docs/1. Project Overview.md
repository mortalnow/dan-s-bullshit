# Project Overview

## What is Dan's Bullshit?

Dan's Bullshit (but's bullshit) is a quote submission and moderation platform built as a FastAPI web application. Users register accounts, submit quotes attributed to "Dan," and admins review and approve them before they appear on the public-facing homepage. Think of it as a curated wall of wisdom (and chaos) with a brutalist, neo-magazine visual style.

The Chinese name is **但言弹语** and the tagline is: *"Approved wisdom, unapproved chaos."*

## Core Purpose

- Let friends of Dan submit memorable quotes
- Give admins editorial control through a moderation queue (approve/reject/edit)
- Serve approved quotes to the public via a fun, shuffle-based "quote dispenser" UI
- Support community engagement through likes ("Oh, Shit!" button) and donations

## Technology Stack

| Layer | Technology | Why |
|---|---|---|
| **Language** | Python 3.9+ | FastAPI ecosystem, async support |
| **Framework** | FastAPI 0.115 | Modern async web framework with automatic OpenAPI docs |
| **Templating** | Jinja2 3.1 | Server-rendered HTML pages |
| **Database (prod)** | MongoDB Atlas via Motor 3.6 | Async MongoDB driver, cloud-hosted |
| **Database (local)** | SQLite via stdlib `sqlite3` | Zero-config local development |
| **Auth** | PyJWT 2.10 | JWT token verification for production; cookie-based sessions |
| **Validation** | Pydantic 2.10 | Request/response models, settings parsing |
| **HTTP Client** | httpx 0.28 | Used in test scripts |
| **Package Manager** | `uv` | Fast Python package manager (replaces pip) |
| **Server** | Uvicorn 0.34 | ASGI server with hot-reload |

## Key Features

- **Quote Dispenser** -- AJAX-powered random quote shuffle on the homepage, no page reload needed
- **User Registration & Approval** -- self-service registration with admin approval gate
- **Role-Based Access** -- admins get moderation tools; regular users see their own submission history and can resubmit rejected quotes
- **Dual Database Mode** -- `LOCAL_MODE=1` uses SQLite for development; `LOCAL_MODE=0` uses MongoDB Atlas for production
- **Like System** -- unauthenticated "Oh, Shit!" button with live counter per quote
- **Bulk Moderation** -- approve or reject all pending quotes at once
- **Content Deduplication** -- SHA-256 hash prevents the same quote from being submitted twice
- **Mobile-First UI** -- safe-area support for iPhone notch/Dynamic Island, touch-optimized 44px button targets, iOS zoom prevention
- **Donate Modal** -- QR code popup for supporting the project

## Getting Started

### 1. Install uv
```bash
brew install uv
```

### 2. Create virtualenv and install dependencies
```bash
uv sync
```

### 3. Configure environment
Create `.env` in the project root:
```env
LOCAL_MODE=1
ADMIN_EMAILS=you@example.com
ADMIN_PASSWORD=your_password
ADMIN_NAME=YourName
```

### 4. Start the server
```bash
uv run uvicorn app.main:app --reload
```

Visit `http://127.0.0.1:8000` -- the admin account defined in `.env` is auto-created on first startup in local mode.

### 5. Run the E2E test (optional)
```bash
uv run python scripts/test_user_flow.py --cleanup
```

## Architecture Summary

The app follows a **monolithic server-rendered architecture** with a thin JSON API layer on top:

- **Server-rendered pages** via Jinja2 templates handle all user-facing flows (registration, login, submission, moderation)
- **JSON API endpoints** (`/api/...`) power the AJAX shuffle, like button, and can be consumed by external clients
- **Database abstraction** through duck-typed store classes (`MongoQuoteStore` / `LocalQuoteStore`) that share the same async method signatures
- **Cookie-based auth** with role-encoded tokens (`email:password:role`) stored as HTTP-only cookies

Detailed architecture is covered in [2. Architecture Overview.md](./2.%20Architecture%20Overview.md).
